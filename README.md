# Site vitrine — Élodie Martin

Site vitrine responsive pour une diététicienne-nutritionniste, réalisé en HTML, CSS et JavaScript sans dépendance de compilation.

## Aperçu

- Accueil et approche
- Accompagnements
- Déroulement des consultations et tarifs indicatifs
- Présentation de la praticienne
- Carnet de conseils
- Coordonnées et formulaire de contact
- Navigation mobile, palette violette douce, mise en page responsive

## Personnalisation avant publication

Les éléments de démonstration doivent être remplacés : nom, diplôme et parcours, spécialités, adresse, horaires, tarifs, adresse e-mail, mentions légales et politique de confidentialité. Les images et polices externes nécessitent une connexion internet. Le formulaire actuel utilise `mailto` ; pour recevoir les demandes de manière fiable, le connecter à un service ou backend de formulaires et ajouter les informations de confidentialité requises.

Ouvrir `index.html` dans un navigateur pour prévisualiser le site.
